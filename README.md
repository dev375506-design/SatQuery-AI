# 🛰️ SatQuery AI

> **Ask questions. Discover changes. Understand Earth.**

SatQuery AI is an **agentic AI-powered remote sensing platform** that transforms satellite imagery into actionable insights through natural-language queries.

Instead of manually interpreting complex satellite data, users can simply **ask what they want to know** and let the system route the task through specialized analysis pipelines.

---

## ✨ What Can It Do?

- 🖼️ **Single-Image VQA** — Ask natural-language questions about satellite imagery.
- 🔄 **Bi-Temporal Change Analysis** — Compare imagery from different time periods and identify meaningful changes.
- 🛰️ **Optical + SAR Fusion** — Combine complementary satellite modalities for enhanced built-area analysis.
- 🧠 **Agentic Model Routing** — Dynamically select the appropriate analysis workflow based on the user's query.
- 📊 **Visual Evidence** — Generate interpretable visual outputs supporting analytical results.
- 🎯 **Confidence Scoring** — Provide confidence-aware responses for model predictions.
- 🔍 **AI Execution Trace** — Make the analysis workflow more transparent and explainable.

---
